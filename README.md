## 📌 Project Overview

PocketSmart AI is a web-based smart budget and recommendation assistant that helps users track expenses, manage monthly budgets, set savings goals, visualize spending, scan receipts, export transaction data, and receive AI-assisted financial recommendations.

### Target Users

Students, young professionals, and budget-conscious individuals who want a simple personal-finance dashboard.

## ✨ Key Features

- 🔐 User Registration / Login
- 💸 Expense Tracking
- 📊 Spending Analytics
- 💰 Budget Management
- 🎯 Savings Goals
- 🤖 AI Recommendations
- 📷 Receipt OCR
- 📁 CSV Export
- 🌓 Dark / Light Mode

## ⚙️ Setup

The executable project uses Python and Flask.

```bash
pip install -r requirements.txt
python app.py
```
Then open `http://localhost:5000`.

The application is served through Flask.

For AI features, Google Gemini configuration is required. AI functionality is environment-dependent.

## 🔒 Security

The project includes:

- Password hashing
- JWT verification
- Authenticated endpoints
- Security response headers
- In-memory rate limiting

API secrets should be provided through environment configuration and should not be committed to source control.
